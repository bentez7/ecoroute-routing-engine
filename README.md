# EcoRoute Routing Service

Energy-aware routing microservice for Malaysia, built on [NREL RouteE Compass](https://nrel.github.io/routee-compass). Exposes a REST API that returns energy-optimal, time-optimal, and balanced route alternatives as encoded polylines.

---

## Prerequisites

- [Miniconda](https://docs.conda.io/en/latest/miniconda.html)
- The `routee-compass` conda environment (see setup below)
- Malaysia road network dataset in `malaysia/` (generated by `setup.py`)

---

## Setup

### 1. Create the conda environment

```bash
conda create -n routee-compass python=3.11
conda activate routee-compass
pip install nrel-routee-compass fastapi uvicorn polyline python-dotenv osmnx elevation rasterio
```

### 2. Generate the Malaysia road network dataset

Downloads OSM road data and elevation tiles for all of Malaysia and processes them into the RouteE Compass format. Takes 3–5 hours.

```bash
conda activate routee-compass
caffeinate -dims python setup.py
```

Output is written to the `malaysia/` folder.

### 3. Configure the API key

Edit `.env` and set a strong secret key:

```
ROUTEE_API_KEY=your-secret-key-here
COMPASS_CONFIG=malaysia/osm_default_energy.toml
```

### 4. Start the server

```bash
conda activate routee-compass
uvicorn server:app --host 0.0.0.0 --port 8080
```

The server loads the Malaysia dataset into memory on startup (~30–60 seconds). Once ready it prints `CompassApp ready.`

### `POST /route`

Compute routes between two coordinates. Returns 3 alternatives in one call.

**Headers**

| Header | Value |
|--------|-------|
| `Content-Type` | `application/json` |
| `X-API-Key` | Your secret key from `.env` |

**Request body**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `origin_x` | float | Yes | Origin longitude (e.g. `101.711`) |
| `origin_y` | float | Yes | Origin latitude (e.g. `3.157`) |
| `destination_x` | float | Yes | Destination longitude |
| `destination_y` | float | Yes | Destination latitude |
| `model_name` | string | No | Vehicle model name (default: `2016_TOYOTA_Camry_4cyl_2WD`) |

**Example request**

```bash
curl -X POST http://localhost:8080/route \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-secret-key-here" \
  -d '{
    "origin_x": 101.711,
    "origin_y": 3.157,
    "destination_x": 101.689,
    "destination_y": 3.156,
    "model_name": "2016_TOYOTA_Camry_4cyl_2WD"
  }'
```

**Response**

```json
{
  "routes": [
    {
      "name": "least_time",
      "summary": {
        "trip_distance_miles": 2.76,
        "trip_time_minutes": 6.0,
        "trip_energy_liquid_gallons": 0.134,
        "trip_elevation_gain_miles": 0.069,
        "trip_elevation_loss_miles": 0.062
      },
      "geometry": "ofjcA_y}mNUYk@o@wAyA..."
    },
    {
      "name": "least_energy",
      "summary": { "..." : "..." },
      "geometry": "..."
    },
    {
      "name": "balanced",
      "summary": { "..." : "..." },
      "geometry": "..."
    }
  ]
}
```

**Route names**

| Name | Optimises for |
|------|--------------|
| `least_time` | Fastest route (minimise travel time) |
| `least_energy` | Most fuel/energy efficient route |
| `balanced` | Balance of distance, time, and energy |

**Summary fields and units**

| Field | Unit | Multiply by to convert |
|-------|------|------------------------|
| `trip_distance_miles` | Miles | × 1.609 → km |
| `trip_time_minutes` | Minutes | — |
| `trip_energy_liquid_gallons` | Gallons (GGE) | × 3.785 → litres |
| `trip_elevation_gain_miles` | Miles uphill | × 1.609 → km |
| `trip_elevation_loss_miles` | Miles downhill | × 1.609 → km |

## The `geometry` Field — Encoded Polyline

### What it is

The `geometry` field is a **Google Encoded Polyline** string — a compact ASCII representation of all the road coordinates along the route.

Example: `ofjcA_y}mNUYk@o@wAyA...`

This encodes a list of `(latitude, longitude)` pairs. Raw GeoJSON for the same route would be ~15 KB. The encoded polyline is ~0.8 KB — about 95% smaller.

When decoded, you get back the full sequence of GPS coordinates that trace the road path from origin to destination.

### Decode in Node.js (backend)

```bash
npm install @mapbox/polyline
```

```js
const polyline = require('@mapbox/polyline');

// Decode returns array of [lat, lng] pairs
const coordinates = polyline.decode(geometry);
// e.g. [[3.157, 101.711], [3.1572, 101.7115], [3.1580, 101.712], ...]

// Convert to GeoJSON [lng, lat] format for Mapbox GL
const geojsonCoords = coordinates.map(([lat, lng]) => [lng, lat]);
```

### Decode in Python

```python
import polyline

coordinates = polyline.decode(geometry)
# Returns list of (lat, lng) tuples
# e.g. [(3.157, 101.711), (3.1572, 101.7115), ...]
```

### Use with Mapbox Map Matching API

Send decoded coordinates to Mapbox Map Matching to get turn-by-turn instructions. Map Matching accepts max 100 coordinates, so downsample first if the route is long.

```js
const polyline = require('@mapbox/polyline');
const simplify = require('simplify-js'); // npm install simplify-js

function decodeAndDownsample(encodedGeometry, maxPoints = 100) {
  const coords = polyline.decode(encodedGeometry); // [[lat, lng], ...]

  if (coords.length <= maxPoints) return coords;

  // Ramer-Douglas-Peucker downsampling
  const points = coords.map(([lat, lng]) => ({ x: lng, y: lat }));
  const simplified = simplify(points, 0.0001, true).slice(0, maxPoints);
  return simplified.map(p => [p.y, p.x]); // back to [lat, lng]
}

// Build Mapbox Map Matching request
async function getMapMatchedRoute(encodedGeometry) {
  const coords = decodeAndDownsample(encodedGeometry);

  // Mapbox Map Matching expects: lng,lat;lng,lat;...
  const coordStr = coords.map(([lat, lng]) => `${lng},${lat}`).join(';');

  const url = `https://api.mapbox.com/matching/v5/mapbox/driving/${coordStr}` +
    `?steps=true&geometries=polyline&overview=full&access_token=YOUR_MAPBOX_TOKEN`;

  const response = await fetch(url);
  return response.json();
}
```

### Coordinate order — important

| Context | Order | Example |
|---------|-------|---------|
| This API — encoded polyline, after decode | `[lat, lng]` | `[3.157, 101.711]` |
| GeoJSON / Mapbox GL source | `[lng, lat]` | `[101.711, 3.157]` |
| Mapbox Map Matching URL | `lng,lat` semicolon-separated | `101.711,3.157` |

Always flip lat/lng when converting between polyline and GeoJSON.

## Notes

- **Keep the server running.** The Malaysia dataset takes ~30–60 seconds to load into memory. Do not restart it on every request.
- **Do not commit `.env`.** Add it to `.gitignore`.
- **Energy unit**: `trip_energy_liquid_gallons` is in US gallons of gasoline equivalent (GGE). Multiply by `3.785` for litres.
- **Distance unit**: All distance values are in miles. Multiply by `1.609` for kilometres.
- **Time unit**: `trip_time_minutes` is in minutes.
